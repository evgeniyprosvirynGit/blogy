## Blogy

Тестовое задание: простой блог на `PHP 8.1+`, `Smarty`, `MySQL` без использования фреймворков.

## Стек

- `PHP`
- `Smarty`
- `MySQL`
- `Phinx` для миграций и сидов
- `Vite` + `Tailwind CSS` для фронтенда
- `Redis` для кэша и soft rate limit
- `Pest` для тестов
- `DDEV` для локального запуска

В проекте не используется полноценный PHP-фреймворк. `illuminate/database` применяется только как ORM/query builder компонент.

## Быстрый запуск через DDEV

### Установка

```bash
git clone <repo-url>
cd blogy
ddev start
ddev composer install
npm install
cp .env.example .env
```

### Миграции и сидинг

```bash
ddev composer migrate
ddev composer seed
```

### Сборка фронтенда

Для production-сборки:

```bash
npm run build
```

Для режима разработки:

```bash
ddev npm run dev
```

### Открыть проект

```bash
ddev launch
```

По умолчанию проект доступен по адресу:

```text
https://blogy.ddev.site
```

или 

```text
ddev describe
```

## Полезные команды

```bash
ddev composer test
ddev composer migrate
ddev composer seed
npm run build
ddev npm run dev
```

Если нужен SQL query log:

```env
DB_QUERY_LOG=true в .env
```

После этого запросы будут писаться в:

```text
storage/logs/sql.log
```

## Структура проекта

Архитектуру проекта сециально реализовал как просто MVC так как не считаю что для проекта такого объема нужна другая.
DTO Сервисы и репозитории также не добавлял, так как посчитал избыточным. В проекте есть дополнительный слой Classes
помогающий работать с сущностями вроде пагинации, сортировки или оптимизатором изображений. 

```text
config/       конфигурация приложения, БД, Redis, кэша, изображений
database/     миграции и сиды
public/       точка входа и собранные ассеты
resources/    фронтенд-ассеты
src/          core, контроллеры, модели, служебные классы
storage/      логи, кэш Smarty
templates/    шаблоны Smarty
tests/        feature и unit тесты
```

Примечание: в проекте используется `Tailwind CSS`, вместо `SCSS`.

Архитектурные решения, структура проекта,
